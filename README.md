# Soniye Photo Lab

A static, GitHub Pages-ready surprise photo studio. Upload a photo, optionally add ID-card details, then let Soniye randomly select one of 120 visual concepts and generate a downloadable high-resolution PNG entirely in your browser.

## What it does

- Uses a centered portrait crop. A static browser app cannot truly choose a better face angle from a single photo without a hosted AI-vision service.
- Contains 120 randomized concepts including retro lab/press cards, comic covers, posters, zines, tickets, postcards, and collectible-style graphics. ID card data only appears when an ID concept is selected.
- Runs locally: uploaded photos are never sent anywhere.

## GitHub Pages

Upload this folder’s contents to a GitHub repository, then set **Settings → Pages → Deploy from a branch → main / root**. Open the published URL and upload a photo.
